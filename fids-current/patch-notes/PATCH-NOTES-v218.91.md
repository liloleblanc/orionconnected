# v218.91 — Light Gate Rescue

This pass removes the gloomy all-dark gate treatment and restores a brighter, more balanced airport-display feel.

## Changes
- Reworked the gate page into a light, symmetrical three-column layout.
- Brightened the top destination/header row and removed the black AC slab look.
- Left aircraft column is now a clean white information card.
- Inbound origin and arrival countdown remain visible.
- Aircraft image stays anchored at the bottom, with Aircraft Type directly beneath it.
- Middle ad area is now a bright framed billboard, not a dark empty console.
- Map column now has a clean white frame and lighter visual treatment.
- Air Canada ad slides are no longer forced to pure black backgrounds.
- Extra guard against duplicated city code labels in the top header.
