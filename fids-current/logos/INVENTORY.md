## File Format & Naming Conventions

### Formats

- **SVG** (preferred) — vector, scales cleanly. All wordmarks and icon logos.
- **PNG** — raster, used when SVG unavailable. Most hotel chain logos.
- **WebP / AVIF** — modern compression, used for backgrounds.
- **JPG/JPEG** — only for photographic content.
- **EPS** — legacy vector exports kept for archival; not used at runtime.

### Variant suffixes

| Suffix | Purpose |
|--------|---------|
| `-light` / `-wordmark-light` | White/light-ink for dark backgrounds (FIDS table default) |
| `-dark` / `-wordmark-dark` | Dark/black-ink for light backgrounds (cream theme) |
| `-white` | Hardcoded white version (older naming) |
| `-emblem` | Symbol/icon only, no wordmark |
| `-wordmark` | Wordmark text only, no icon |
| `-symbol` | Brand symbol only (similar to emblem) |
| `-stacked` | Vertical/stacked layout variant |
| `-square` / `-long` | Aspect ratio variants |
| `_2017` / `_2018` / `_2019` / `_2024` | Year-of-release for branding refreshes |

### Path resolution at runtime

Static path references in JS (e.g., `/logos/airlines/canadian/air-canada.svg`) point directly at files.

Dynamic path constructions go through `logoPath(basename)` which looks up the basename in the `LOGO_SUBFOLDER` constant. Example:

```js
logoPath("air-canada-wordmark-light.svg")
// → "/logos/airlines/canadian/air-canada-wordmark-light.svg"

logoPath("aircraft-icon.png")  // not in LOGO_SUBFOLDER
// → "/logos/aircraft-icon.png"
```
